# 播放页设计规范（对应 `PlayerMockup.svg`）

设计基准：iPhone 15 Pro 逻辑分辨率 390 × 844 pt，@3x。所有数值与 `Sources/Views/PlayerView.swift`、`LyricsView.swift` 一一对应。

## 1. 图层结构（自底向上）

| 层 | 内容 | 实现 |
| --- | --- | --- |
| L0 | 封面取色双色渐变 | `LinearGradient(colors: store.palette)`，取色由歌名+歌手哈希得出（`ArtworkPalette`），切歌 0.5s 过渡 |
| L1 | 封面高斯模糊（生产环境建议 blur 40 + scale 1.08） | `ArtworkPalette` 备用；原生用渐变代替图片模糊 |
| L2 | 垂直压暗遮罩 | 顶部 35% 黑 → 45% 透明 → 底部 80% 黑，保证白色文字可读 |
| L3 | 状态栏 / 顶栏 | 系统状态栏 44pt；自定义 40pt 控件 |
| L4 | 码率角标（左上，18pt 高胶囊） | 缓冲时文案切为「缓冲中」 |
| L5 | 歌词舞台（flex，占 58% 高度） | Hero 标题 → 歌词行，居中滚动 |
| L6 | 底部信息区（歌名/标签/图标/进度/控制/会员条） | 固定高度，自下而上排布 |

## 2. 间距系统

- 屏幕左右边距 22pt；顶栏 16pt；底部安全区由系统 inset 提供（不再手动加值）
- 垂直节奏：Hero 底 → 歌名区顶部 24pt；标签行底 → 图标行 20pt；图标行底 → 进度 8pt；进度底 → 控制行 6pt；控制行底 → 会员条 6pt
- 触控区最小 44 × 44pt（图标的可见图形可以更小）

## 3. 字号与字重

| 元素 | 字号 | 字重 | 颜色 | 字距 |
| --- | --- | --- | --- | --- |
| Hero 歌名 | 40 | Heavy(800) | #FFF | +6 |
| Hero 歌手 | 20 | Semibold | #FFF 92% | +3 |
| 歌词（当前行） | 22 | Bold | #FFF | 0 |
| 歌词（常规行） | 19 | Regular | #FFF 55% | 0 |
| 歌名（信息区） | 28 | Bold | #FFF | 0 |
| 歌手 | 20 | Regular | #FFF 72% | 0 |
| 标签 | 13 | Regular | #FFF 75% + 描边 35% | 0 |
| 图标说明文字 | 10 | Regular | #FFF 65% | 0 |
| 时间 | 13 | Regular 等宽 | #FFF 70% | 0 |
| 会员条 | 13 | Regular / 强调 600 | #F4D24A | 0 |

## 4. 组件规格

**顶栏**：左收起（chevron.down，2pt 描边）、中 VIP 胶囊（高 40 / 圆角 20 / 白 16% + blur 18 / 内含 24pt 蓝色渐变圆章「免」+ 15pt 文案 + 右尖括号）、右投屏（40pt 圆形，白 12% 底）。

**Hero 标题**：歌词未开始时显示，第一行歌词生效后 0.4s 淡出上移 30pt（避免与歌词抢焦点）。

**歌词**：行间距 36pt；当前行放大到 22pt 并提亮；`ScrollViewReader` 以 `.center` 锚定；上下各 12% 用渐隐遮罩，切歌后 hero 区留 90pt 上内边距。

**标签行**：关注按钮为描边态，选中后反白（白底黑字）；其余标签纯展示；容器横向滚动，隐藏指示器。

**图标行**：6 等分（评论 / 下载·VIP角标 / 设铃声 / 收藏·计数 / 4K / 更多）；收藏点击后 `heart.fill` 变 #FF5A76 + 0.4s scale 1→1.25→1。

**进度条**：轨道 2pt 圆角；已播 #FFF；缓冲 #FFF 30%；未播 #FFF 28%；滑块 12pt 白圆 + 阴影，仅在按压/拖动时显形（常态隐藏）；时间左右对齐、等宽数字。

**控制行**：模式 / 上一首 / 播放 / 下一首 / 列表，各 56 × 56 触控区；播放键 72pt 圆形，白 22% + blur 16 + 内描边高光 1pt；播放中加一圈 1pt/25% 白扩散呼吸动画（2.4s 循环）。

**会员条**：高 44，13pt；菱形图标 + 金色 #F4D24A 13pt；「开会员无限畅享」600 字重 + 右尖括号。

**播放列表抽屉**：圆角 20，背景 #16201D 92% + blur 28；两档 detent（medium / large），带 grabber；行高 58，缩略图 42，当前播放行高亮白 12%。

## 5. 动效

| 动作 | 曲线 |
| --- | --- |
| 歌词行高亮/滚动 | 0.45s easeInOut |
| Hero 淡出 | 0.4s easeInOut |
| 播放页进/出 | spring(response 0.5, damping 0.86)；下拉手势位移 > 90pt 或预测 > 140pt 触发关闭 |
| 背景换色 | 0.5s easeInOut |
| 收藏/模式切换 | Haptics light + 0.2s scale 0.9 按压反馈 |

## 6. 无障碍与对比度

- 白色文字在底部 80% 黑遮罩上对比度 ≥ 7:1；次级文字（72%/65%）≥ 4.5:1
- 语音标签：收起「收起」、播放键「播放/暂停」、上一首/下一首、模式「列表循环/单曲循环/随机播放」、进度「播放进度」
- 支持动态字体：歌词与歌名使用相对文本样式时会自动缩放；如需严格还原可设 `.dynamicTypeSize(...DynamicTypeSize.accession2)` 上下限

## 7. 适配

- 竖屏为主；iPad 允许四方向并把控制行放大到 80pt
- 刘海/home indicator 区全部交给 safeArea，背景渐变用 `.ignoresSafeArea()` 铺满
- 深色锁定：`.preferredColorScheme(.dark)`，避免浅色下白字不可读
