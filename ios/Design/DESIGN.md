# 播放页设计规范（沉浸式）

设计基准：iPhone 15 Pro 逻辑分辨率 390 × 844 pt，@3x。对应 `Sources/Views/PlayerView.swift`、`LyricsView.swift`，线框稿见 `Wireframes.html`。

## 1. 图层结构（自底向上）

| 层 | 内容 | 实现 |
| --- | --- | --- |
| L0 | 封面图，`blur 18` + `scaleEffect 1.12`，全屏出血 | 有封面用 `Image(uiImage:)`，无封面用取色板渐变兜底 |
| L1 | 压暗遮罩 | `黑 .28 → 透明 → 透明 → scrim .55 → scrim .90`，scrim 取自封面取色的近黑色 |
| L2 | 状态栏 / 顶栏 | 收起 / 页码点 + 「正在唱」圆章 / 投屏 + 分享 |
| L3 | 码率角标（左上，浮于遮罩之上） | 缓冲时文案切为「缓冲中」 |
| L4 | 歌词舞台（flex，居中偏上） | 当前行 15pt 半粗白字，普通行 12pt 55% |
| L5 | 底部信息区 | 歌名 → 标签行 → 图标行 → 进度 → 控制 → 会员条 |

不设独立封面控件：背景即封面，这是「沉浸」的来源。

## 2. 配色引擎（背景随封面自动改色）

`Sources/Player/ArtworkPalette.swift`，不预设主题色，切歌重新取色。

1. 封面下采样 **32 × 32**（`CGContext` + `interpolationQuality = .medium`）
2. 丢弃相对亮度 **< 0.12 或 > 0.92** 的像素（黑白噪点、留白）
3. 丢弃 OKLab 色度 **C ≤ 0.02** 的灰像素
4. **24 桶色相直方图**取峰值桶，再合并 ±1 桶求平均（避免撞色）
5. 转 **OKLab**：L 夹 **0.22 – 0.55**、C 夹 **≤ 0.19**（保证白字对比度 ≥ 4.5:1）
6. 派生四段渐变（色相 +25° / +180°）：

| 段 | L | C | 用途 |
| --- | --- | --- | --- |
| light | L + 0.16（上限 0.68） | C × 0.8 | 渐变亮端 |
| main | L | C | 主色 |
| dark | L − 0.14（下限 0.14） | C × 1.05 | 渐变暗端 |
| near | L − 0.24（下限 0.10） | C × 0.9，h+180 | 遮罩 scrim |

7. 切歌 0.5s `easeInOut` 过渡；无封面 / 加载失败回退到「歌手-歌名」哈希色板
8. 封面图源优先级：`Song.artworkURL` → `AVURLAsset.commonMetadata` 里的 artwork

## 3. 间距系统

- 屏幕左右边距 **18pt**（信息区）；图标行 14pt；进度条 18pt
- 垂直节奏：标签行底 → 图标行 18pt；图标行底 → 进度 20pt；进度底 → 控制 12pt
- 触控区最小 44 × 44pt（播放键占 72pt 触控区，视觉 52pt）

| 元素 | 字号 | 字重 | 颜色 |
| --- | --- | --- | --- |
| 歌词（当前行） | 15 | Semibold | #FFF |
| 歌词（常规行） | 12 | Regular | #FFF 55% |
| 歌名 | 18 | Bold | #FFF |
| 歌手 | 11 | Regular | #FFF |

## 5. 组件规格

**顶栏**：左收起（chevron.down，20pt）；中 3 点指示器（首点 16pt 胶囊，余 6pt 圆点）+ 右移 34pt 的「正在唱」圆章（26pt 头像 + 9pt 文案）；右投屏 + 分享，间距 18pt。

**歌词**：行间距 14pt；`ScrollViewReader` 以 `.center` 锚定；上下渐隐遮罩；换歌重置到顶部。

**标签行**：歌手纯文字 → 「关注」描边按钮（选中反白）→ tags 胶囊；横向滚动隐藏指示器。

**图标行**：6 等分；下载带金色 VIP 角标；收藏点击 `heart.fill` 变粉；说明文字浮于图标上方。

**进度条**：自绘，2pt 圆角；已播 #FFF；缓冲 #FFF 35%；未播 #FFF 28%；滑块 10pt 白圆，仅按压时显形；`DragGesture(minimumDistance: 0)`，起点触发 Haptics；时间等宽数字左右对齐。

**控制行**：模式 / 上一首 / 播放 / 下一首 / 列表，各 52 × 52 触控区；播放键视觉 52pt 圆形，白 16% + 内描边白 28%；播放中 0→1.16 扩散淡出。

**会员条**：纯文字无底色；钻石金色 → 试听文案 72% → 「开通会员无限畅享」金色 600 → 尖括号。

**播放列表抽屉**：圆角 16，背景 #1E2226 97%；行高约 52，缩略图 34，当前播放行白色。

## 6. 动效

| 动作 | 曲线 |
| --- | --- |
| 背景换色 | 0.5s easeInOut |
| 歌词行高亮/滚动 | 0.45s easeInOut |
| 播放页进/出 | spring(response 0.5, damping 0.86)；下拉位移 > 90pt 或预测 > 140pt 关闭 |
| 收藏/模式切换 | Haptics light |

## 7. 无障碍与对比度

- 取色 C 上限 0.19 + L 夹 0.22–0.55，保证白字在背景上 ≥ 4.5:1；遮罩底部 .9 兜底
- 语音标签：收起、播放/暂停、上一首/下一首、模式、进度
- 深色锁定：`.preferredColorScheme(.dark)`

## 8. 简约原则

1. 全页仅白 + 金色会员强调，无品牌色
2. 背景色只来自封面，不来自主题
3. 不放独立封面卡片 / 唱片 / 旋转动画
4. 功能 ≤ 5 组，分 3 段呼吸：歌词 → 信息 → 控制
5. 文字层级 ≤ 3 级；动效只做淡入淡出 + 高度滚动
